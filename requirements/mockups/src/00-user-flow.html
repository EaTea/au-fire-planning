User flow

How a user moves through the app. First-time users go through the four input steps in order. Returning users land straight on their results. From the results they can drill into the projection, save and compare scenarios, or go back and change any input.

Grey box: numbered step in the header nav. Dashed box: action available from the results.
Dashed arrows: from the results, the user can go back and edit any input. The results recalculate when they return.
All data stays on this device. No backup or sync to other services (§10)
